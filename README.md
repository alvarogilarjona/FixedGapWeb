# FixedGap — Web

Web oficial de FixedGap. Post-stroke rehabilitation platform.
Dominio: fixedgap.com

## Stack
- Next.js 14 con App Router
- TypeScript
- Tailwind CSS

## Paleta de colores
- Navy `#1A1F3C` — texto principal
- Blue `#1F4C9C` — acento, botones
- Beige `#F5F0E8` — fondo alternativo
- Cream `#F7F9FC` — cards
- Border `#E8E0D0` — bordes
- Muted `#6B7689` — texto secundario

## Estructura de la web

### Landing page (/)
Secciones en orden:
1. Hero — headline + subline + CTAs
2. Problem — estadísticas del ictus, el gap entre visitas
3. Solution — qué hace FixedGap y cómo
4. Pipeline — CV Pipeline con 5 pasos (inspiración: runpulse.com)
5. Demo — vídeo demo del producto
6. Traction — logos de partners y credibilidad Harvard
7. Metrics — números de impacto en grande
8. Manifesto — por qué existe FixedGap
9. Team — equipo con fotos, roles y LinkedIn
10. Contact — email + Book a call via Cal.com

### Páginas internas
- /product — detalle técnico, biomarcadores, dashboard, FAQ
- /market — TAM/SAM/SOM, estadísticas de ictus
- /company — historia, misión, Harvard HSIL
- /pricing — tres tiers sin precios, CTA a contacto
- /contact — formulario + email + Cal.com
